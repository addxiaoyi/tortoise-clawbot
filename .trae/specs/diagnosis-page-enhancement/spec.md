# 医生诊断页面完善规格文档

## Why
当前医生诊断页面(DiagnosisPage)虽然具备基础的诊断功能，但存在以下问题：
1. 截图显示页面底部显示"该模块正在从 OpenClaw CLI 迁移并进行可视化重构"的占位提示，说明功能尚未完全实现
2. 诊断结果展示不够直观，缺乏可视化图表和趋势分析
3. 修复操作流程不够清晰，用户难以理解修复进度和结果
4. 缺少历史诊断记录功能，无法追踪系统健康状态变化
5. 检查项(环境检查、配置校验、网关探测、安全审计)缺乏详细的子项展示

## What Changes
- 完善四大检查模块的可视化展示：环境检查、配置校验、网关探测、安全审计
- 添加诊断历史记录功能，支持查看历史诊断结果对比
- 优化修复流程的进度展示，增加可视化进度条和步骤指示
- 添加系统健康度评分图表，直观展示整体状态
- 实现检查项的详细展开/收起功能
- 添加一键导出诊断报告为PDF功能
- 优化空状态和加载状态的UI展示

## Impact
- 受影响文件：
  - `tortoise/src/pages/DiagnosisPage.tsx` - 主要修改
  - `tortoise/src/components/` - 可能需要新增图表组件
  - `tortoise/src/lib/tauri.ts` - 可能需要新增后端接口调用
  - `tortoise/src/store/useAppStore.ts` - 可能需要新增诊断历史状态

## ADDED Requirements

### Requirement: 检查模块可视化展示
系统 SHALL 提供四大检查模块的详细可视化展示

#### Scenario: 环境检查模块
- **WHEN** 用户展开"环境检查"模块
- **THEN** 系统显示以下子项：
  - Node.js 版本检查
  - Python 环境检查
  - 系统依赖检查
  - 磁盘空间检查
  - 内存使用情况
  - 网络连接状态

#### Scenario: 配置校验模块
- **WHEN** 用户展开"配置校验"模块
- **THEN** 系统显示以下子项：
  - API Key 配置有效性
  - 飞书配置完整性
  - 代理设置检查
  - 模型配置验证
  - 插件配置检查

#### Scenario: 网关探测模块
- **WHEN** 用户展开"网关探测"模块
- **THEN** 系统显示以下子项：
  - 网关运行状态
  - 端口占用检查
  - 进程状态检查
  - 服务响应时间
  - 飞书连接状态

#### Scenario: 安全审计模块
- **WHEN** 用户展开"安全审计"模块
- **THEN** 系统显示以下子项：
  - API Key 安全存储检查
  - 配置文件权限检查
  - 敏感信息泄露检查
  - 工作区提示词隔离状态
  - 插件白名单锁定状态

### Requirement: 诊断历史记录
系统 SHALL 保存并展示最近30天的诊断历史记录

#### Scenario: 查看历史记录
- **WHEN** 用户点击"历史记录"按钮
- **THEN** 系统显示历史诊断列表，包含：
  - 诊断时间
  - 整体健康评分
  - 问题数量统计
  - 修复状态标记

#### Scenario: 历史记录对比
- **WHEN** 用户选择两个历史记录进行对比
- **THEN** 系统显示对比视图，突出显示改善和恶化项

### Requirement: 系统健康度评分
系统 SHALL 提供直观的健康度评分展示

#### Scenario: 健康度评分展示
- **WHEN** 诊断完成后
- **THEN** 系统在页面顶部显示：
  - 总体健康度评分(0-100)
  - 评分趋势箭头(上升/下降)
  - 与上次诊断的评分对比
  - 健康状态等级(优秀/良好/一般/差)

#### Scenario: 健康度详情
- **WHEN** 用户点击健康度评分
- **THEN** 系统显示各模块的评分详情和权重说明

### Requirement: 优化修复流程
系统 SHALL 提供清晰直观的修复流程展示

#### Scenario: 修复进度展示
- **WHEN** 用户执行一键修复
- **THEN** 系统显示：
  - 当前修复步骤名称
  - 进度百分比
  - 已修复/总问题数
  - 预计剩余时间
  - 实时日志输出

#### Scenario: 修复结果展示
- **WHEN** 修复完成后
- **THEN** 系统显示：
  - 修复成功/失败统计
  - 需要手动处理的问题列表
  - 建议的后续操作

### Requirement: 诊断报告导出
系统 SHALL 支持导出诊断报告

#### Scenario: 导出PDF报告
- **WHEN** 用户点击"导出报告"按钮
- **THEN** 系统生成PDF格式的诊断报告，包含：
  - 诊断时间戳
  - 系统信息摘要
  - 所有检查项结果
  - 修复建议
  - 历史趋势图表
