# 完善多核心 Agent 支持与新手老手切换规范

## Why

当前 tortoise 项目已实现多核心 Agent 支持和新手/老手模式选择，但需要全面验证和确保所有功能完整可用。需要验证：
1. 入场动画正确播放
2. 核心选择流程完整
3. 新手/老手模式切换功能正常
4. 关于我们页面可重新选择核心
5. 所有 Tauri API 调用在浏览器环境中不会崩溃

## What Changes

### 1. 功能验证清单
- 入场动画播放验证
- 核心选择界面验证
- 模式选择界面验证
- 关于我们页面核心切换验证
- 技能页面插件兼容性标签验证

### 2. 错误修复
- Tauri API 浏览器环境兼容处理
- 所有 `invoke`、`getCurrentWindow`、`openUrl` 调用添加错误处理

### 3. UI/UX 完善
- 确保中文字符串完整显示
- 确保动画流畅
- 确保状态持久化正确

## Impact

### 受影响的代码
- src/App.tsx - Tauri API 错误处理
- src/pages/AboutPage.tsx - openUrl 错误处理
- src/components/SplashScreen.tsx - 核心选择流程
- src/pages/SkillsPage.tsx - 插件兼容性标签

## ADDED Requirements

### Requirement: 完整功能验证
系统 SHALL 验证以下功能完整可用：
1. 入场动画默认每次启动播放
2. 动画后可跳过
3. 核心选择界面显示三个核心选项
4. 每个核心显示优缺点
5. 模式选择界面显示新手/老手选项
6. 关于我们页面显示当前核心
7. 可在关于我们页面重新选择核心

### Requirement: 浏览器环境兼容
系统 SHALL 在浏览器开发环境中不崩溃，所有 Tauri API 调用添加错误处理。

### Requirement: 状态持久化
系统 SHALL 正确保存用户选择的核心和模式，重启后保持选择。
